# 🎓 AcadFlow - Academic Assignment & Deadline Tracker

An intelligent, zero-backend Learning Management System (LMS) designed to solve the problem of scattered assignment deadlines. AcadFlow provides a unified dashboard for students to track tasks and for teachers to manage grading seamlessly.

## 🚀 The Problem We Solved
Students often miss deadlines because assignments are scattered across different subjects, teachers, and notice boards. There was no single, unified dashboard to see everything that is due, mark what is completed, and track overall academic progress.

## ✨ Key Features
*   **Dual Portals:** Dedicated, secure dashboards for both Students and Teachers.
*   **Smart Deadline Tracking:** Automatically sorts tasks by urgency, highlighting overdue and upcoming assignments.
*   **Real-time Analytics:** Interactive charts (via Recharts) displaying subject-wise completion rates and overall progress.
*   **Zero-Backend Architecture:** Fully serverless data layer utilizing IndexedDB (Dexie.js). Data persists directly in the browser, ensuring blazing-fast, offline-capable performance without API lag.
*   **Premium UI:** Clean, modern, responsive design built with Tailwind CSS and Lucide React icons.

## 💻 Tech Stack
*   **Frontend:** React, Vite
*   **Styling:** Tailwind CSS
*   **Database:** Dexie.js (IndexedDB) for local, persistent client-side storage
*   **Data Visualization:** Recharts
*   **Icons:** Lucide React
